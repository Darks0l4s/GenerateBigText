# 🚀 Генератор больших тестовых файлов на `yield` и бенчмарк поиска (`list` vs `set`/`dict`)

![Python](https://img.shields.io/badge/Python-3.10%2B-blue?style=for-the-badge&logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)

Интерактивная консольная утилита на Python для наглядной демонстрации работы **генераторов (`yield`)**, оценки потребления оперативной памяти с помощью модуля `tracemalloc` и сравнения алгоритмической сложности поиска элементов в различных структурах данных (`list`, `set`, `dict`).

---

## 📋 О проекте

При работе с большими объёмами данных (Big Data, парсинг логов, генерация тестовых датасетов) классический подход с хранением всех данных в памяти (`return`) приводит к резкому росту потребления RAM. 

Данный проект решает две учебные и практические задачи:
1. **Ленивые вычисления (Lazy Evaluation):** Сравнение пикового потребления оперативной памяти при генерации файла с помощью генератора `yield` ($O(1)$ по памяти) и обычного формирования строки в памяти ($O(n)$ по памяти).
2. **Алгоритмическая сложность поиска:** Бенчмарк скорости поиска элемента в списке (`list` — линейный поиск $O(n)$) по сравнению с хеш-таблицами (`set` и `dict` — константный поиск $O(1)$).

---

## ✨ Функциональность

- **Генерация тестового файла (`file.txt`)** заданного размера из случайных латинских букв и цифр.
- **Профилирование памяти:** замер пикового использования RAM в байтах через встроенный модуль `tracemalloc` и расчёт коэффициента экономии памяти.
- **Бенчмарк поиска:** высокоточный замер времени поиска заданного символа с помощью `time.perf_counter()` по трём структурам данных: `list`, `set` и `dict`.
- **Интерактивное CLI-меню** на базе конструкции `match / case`.

## 📊 Выводы по результатам работы

| Критерий | `return` (Строка целиком) | `yield` (Генератор) |
| :--- | :--- | :--- |
| **Потребление RAM** | Растёт линейно $O(n)$ от размера файла | Константное $O(1)$, не зависит от размера файла |
| **Масштабируемость** | Ограничена объёмом оперативной памяти | Позволяет генерировать файлы на десятки гигабайт |

| Структура данных | Внутреннее устройство | Сложность поиска | Скорость |
| :--- | :--- | :--- | :--- |
| `list` | Динамический массив | $O(n)$ | Медленно на больших объёмах |
| `set` | Хеш-таблица | $O(1)$ | Мгновенно |
| `dict` | Хеш-таблица | $O(1)$ | Мгновенно |
